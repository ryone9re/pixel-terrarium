# Pixel Terrarium

毎日少しずつ育つボクセル風テラリウムを、アプリとホーム画面ウィジェットで眺める iOS 26 アプリです。

## 必要環境

- Xcode 26.6 / Swift 6.3.3
- iOS 26.5 Simulator
- Tuist 4.202.8
- SwiftLint 0.65.0
- xcbeautify 3.2.1
- Blender 5.2.0 LTS

## プロジェクト生成

```sh
tuist generate --no-open
open PixelTerrarium.xcworkspace
```

詳しい実装・検証手順は開発の進行に合わせて追記します。
