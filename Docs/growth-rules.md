# 育成ルール

育成状態は、保存済みの状態と作成時タイムゾーンの暦日から決定的に算出します。

午前0時を越えるたび、直前の日の水分が40以上なら成長ポイントを1増やします。
その後に新しい日の水分を20減らします。
水やりは同じ暦日に一度だけ受理し、水分を最大100まで50増やします。

端末時刻が `lastResolvedDay` より前へ戻っても、保存済みの水分と成長ポイントは変更しません。

## 景色への反映

成長ポイントは7段階の名称に変換されますが、景色は段階別の固定モデルではありません。
苔の群生数と大きさは成長ポイントに応じて増え、発芽後はシダの本数と小葉の数も増えます。
水分が40未満になると苔とシダの色を乾いた黄緑へ変え、ガラス面の水滴を減らします。
