# アーキテクチャ

## 状態と景色の分離

`TerrariumCore`はFoundationだけに依存し、育成計算、手続き型レイアウト、Widget用スナップショットを提供します。

**手続き型レイアウト**は、テラリウム固有のシード、成長ポイント、水分量から苔、シダ、石、朽木、水滴の配置を算出した値です。
乱数生成器をシードで初期化するため、同じ入力からは同じ配置を再現します。
成長時は既存の苔の位置を保ったまま、群生数、半径、高さ、シダの葉数を増やします。

## アプリの描画

アプリ本体はSwiftDataで育成状態を保存します。
RealityKitはBlender製の共通外装を読み込み、手続き型レイアウトから容器内のModelEntityを組み立てます。
夜間は暖色のキーライトと青色のフィルライトを使い、水分が40以上ならガラス面の水滴と光点を表示します。

## Widgetの再構成

アプリはApp Groupへ、シードと育成状態をJSONで原子的に書き込みます。
WidgetはJSONを読み取り、アプリと同じ手続き型レイアウトをSwiftUI Canvasへ投影します。
保存するのは画面のビットマップではなく景色を再現できる状態なので、Widgetのタイムラインが日付境界を処理した場合も成長後の景色を描けます。

## 更新の流れ

```text
SwiftDataの育成状態
  -> TerrariumCoreの決定的な育成計算
  -> シード付き手続き型レイアウト
     -> RealityKitの3D表示
     -> WidgetのCanvas表示
  -> App GroupのJSONスナップショット
```
