# アーキテクチャ

## 状態と景色の分離

`TerrariumCore`はFoundationだけに依存し、育成計算、手続き型レイアウト、Widget用スナップショットを提供します。

**手続き型レイアウト**は、テラリウム固有のシード、成長ポイント、水分量から苔、シダ、石、朽木、水滴の配置を算出した値です。
乱数生成器をシードで初期化するため、同じ入力からは同じ配置を再現します。
成長時は既存の苔の位置を保ったまま、群生数、半径、高さ、シダの葉数を増やします。

## アプリの描画

アプリ本体はSwiftDataで育成状態を保存します。
RealityKitはBlender製の共通外装を読み込み、手続き型レイアウトから容器内のModelEntityを組み立てます。
視点には透視カメラを明示的に置き、ガラス中心より少し上から約8度見下ろします。アプリとウィジェットの描画は同じカメラ姿勢を共有します。
容器の底は排水層、炭、厚い土、緩やかに起伏する苔面の順に重ね、土の外周はガラス内壁の曲率へ沿わせます。
地表全体の基準面を容器底から高くし、上部の余白を抑えながら苔面を斜め上から見渡せる構図にします。
ガラスは中央が膨らみ、台座側と短い首へ向かってすぼまる球体形状です。
土は内壁まで満たし、苔面と主要な植物配置は外周より少し内側へ収めることで密度と奥行きを両立します。
苔と石は、少数の共有メッシュをシード付きで使い分けることで、真球ではない有機的な輪郭を作ります。
モデルを景色ごとに書き出さないため、成長に応じて群落を追加してもアプリ容量は増えません。

土、苔、石、枝、葉、金属、ガラスにはRealityKitのPBR材質を使います。
水分が40以上になると苔と石の粗さ、反射、クリアコートが変化し、ガラス内壁には透明な3D水滴を配置します。
水滴は高分割の非対称レンズ形状を球面全周の内壁へ分散し、透明描画順と前面ハイライトを回転角へ追従させます。
夜間は暖色のキーライト、容器内のランタン光、青色のリムライトを組み合わせ、水滴と微粒子だけに強い輝きを与えます。
苔本体の反射は抑え、濡れた植物がプラスチックに見えない範囲へ留めます。

有機メッシュは苔房5種類、石4種類、シダ、傾斜地形、朽木を初回生成後にキャッシュします。
苔は10個の大小の葉状塊を1メッシュへ結合し、地形全体の24基準点へ低い面状パッチを最大42枚まで広げます。
各パッチは成熟時の外周寸法を先に見積もり、中心を土面の輪郭内へ寄せることで成長後も縁からはみ出さないようにします。
排水層と炭の上にはガラス内壁へ沿う土メッシュを置き、成長初期は土面を広く露出させます。
地表外周の苔は成長ポイントに応じて0房から24房まで増え、土面の輪郭より内側かつ上側で縁へ徐々に到達します。
中央へまとめた景石には、石と同じ多角形の上面、肩、側面へ沿う苔の外皮を成長段階ごとに広げます。
シダは茎の管状メッシュと、表裏、側面、盛り上がった葉脈を持つ小葉を1枚のフロンドへ結合し、最大6 ModelEntityに抑えます。
成熟したシダは左奥、右側、手前の複数の株元へ分散し、株ごとに高さと向きを変えます。
これにより細かな輪郭を増やしながら、成熟時の回転に必要なEntity更新数を以前の数百個から数十個へ減らします。

苔のPBR材質には、実写調のマクロ表面を元にした専用アルベドテクスチャを使います。
濡れた石だけに控えめなクリアコートを与え、ガラスは低い面不透明度と球面のPBR反射で輪郭を作り、水分は球面に沿う独立した3D水滴で表現します。
台座は球体の底面よりわずかに広い小径の黒染め金属とし、細い真鍮の縁だけをアクセントにします。
接地感は方向光の影と、地形の高低に沿った配置で補います。

## Widgetの3Dスナップショット

アプリは、アプリ画面と同じ`TerrariumSceneFactory`からRealityKitの景色を組み立て、朝、昼、夕方、夜の4種類を世代付きの透過PNGとしてApp Groupへ保存します。
4枚すべてが完成した後、その世代番号と育成状態を含む公開情報JSONを原子的に切り替えます。
Widgetは表示時刻に合う画像を読み取るため、苔、石、シダ、ガラス、水滴、台座、照明がアプリと一致します。

PNGがまだ生成されていない初回表示は準備中表示とし、異なる描画方式でテラリウムを代用しません。
更新中は直前の完成済み世代を表示し続けるため、新しい育成状態と古い画像が混在しません。
画像生成はアプリ起動時、日付解決時、水やり時に非同期で実行し、公開情報JSONの切り替えが完了してからWidgetのタイムラインを一度だけ再読み込みします。
Widgetは保存済みの育成状態を表示し、日付をまたいだ成長と水分更新は次にアプリが状態を解決した時点で画像と一緒に反映します。

## 更新の流れ

```text
SwiftDataの育成状態
  -> TerrariumCoreの決定的な育成計算
  -> シード付き手続き型レイアウト
     -> 共通のRealityKitシーン
        -> アプリの3D表示
        -> 時間帯別の透過PNG
  -> App Groupの世代付きPNG
  -> 完成後に公開情報JSONを原子的に切り替え
  -> Widget表示
```
